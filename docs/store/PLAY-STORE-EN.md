# Google Play listing · English

**Title (24/30):** RideScreen AA: Moto Dash

**Short description (73/80):** Wireless Android Auto for compatible Carbit/EasyConnect motorcycle displays.

**Full description (under 4,000 characters):**

Bring Android Auto to a compatible motorcycle dashboard from your Android phone over Wi-Fi. RideScreen AA is an independent fork of OpenCfMoto for Carbit/EasyConnect dashboards that use a MotoPlay screen-mirroring interface. Compatibility depends on the motorcycle and dashboard; it has been tested on a Zontes 125X.

**PKE keyless-box controls**

- Read the keyless box's battery voltage and reported lock state over Bluetooth.
- Send explicit lock or unlock commands, or release the seat and fuel cap, from the app or the home-screen widget.
- Set up the PKE code and the McuID from the motorcycle's information QR. The McuID is stored on the device and excluded from Android backups.
- Optionally unlock when you tap Connect. This option is off by default and never unlocks during automatic connection. Seat and fuel-cap commands require confirmation.

The keyless box does not provide full vehicle telemetry. RideScreen AA does not currently read engine RPM or ECU data. The widget does not display the actual lock state; check the battery/status card. Sending a command does not confirm that the motorcycle acted on it, so check the bike.

Projection requires a compatible dashboard and its connection settings. Compatibility with other motorcycles is not guaranteed.
